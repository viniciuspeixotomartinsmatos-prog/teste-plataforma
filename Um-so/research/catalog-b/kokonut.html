03

How to install

Kokonut UI is a shadcn/ui registry, so every component arrives as source in your repo, with its dependencies installed.

  1. AI agentA

    Name a component, or describe what you need. Your agent finds it in the registry and installs it with its dependencies.

  2. shadcn CLIB

    Name the component. The shadcn CLI writes the file and installs what it needs.

  3. RegistryC

    Add the namespace to components.json once, then use the short names everywhere.
