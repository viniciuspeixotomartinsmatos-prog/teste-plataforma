Run the following command

PropTypeDefaultDescription
childrenany-The content to be displayed on top of the wavy background.
classNamestring-The CSS class to apply to the content container.
containerClassNamestring-The CSS class to apply to the main container.

waveWidthnumber50The width of the waves.
backgroundFillstring"black"The background color.

speed"slow" | "fast""fast"The speed of the wave animation.
