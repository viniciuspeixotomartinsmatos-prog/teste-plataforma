# UNION UI source

`App.jsx` owns URL filters, local collections, themes and navigation. `catalog.js` contains catalog search and normalization. `UI.jsx` contains cards and the keyboard search dialog. `Detail.jsx` loads code files only when a component is opened. `Preview.jsx` isolates retained HTML and dynamically compiled examples in sandboxed iframes.

Catalog data is static and local. No account, payment, authentication or private production database is connected.
