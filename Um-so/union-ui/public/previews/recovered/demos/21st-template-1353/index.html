Motoko Base currently uses Polar (opens in a new tab) for payments because it provides checkout, subscriptions, customer management, webhooks and merchant-of-record capabilities in one service.

This keeps the billing infrastructure simple while still covering everything a SaaS product needs.

The billing layer is intentionally isolated from the rest of the application, so switching to another provider such as Stripe later is possible without rewriting your entire app.

Yes.

Motoko Base currently ships with Polar (opens in a new tab), but the rest of the application is not tightly coupled to Polar.

The billing integration is isolated behind a dedicated billing layer, so you can replace Polar with Stripe or another provider when needed.

You will need to implement the provider-specific checkout and webhook logic for the service you choose.

Motoko Base uses the Vercel AI SDK (opens in a new tab), which supports a wide range of AI providers and models.

This lets you integrate providers such as OpenAI, Anthropic, Google Gemini, Mistral, xAI, DeepSeek and others without building a completely different architecture for each one.

The starter also includes an AI Email demo showing how AI functionality can be integrated into a real application.

Motoko Base is actively developed and will receive updates as the stack evolves.

Your purchase includes lifetime updates, so you don't need to buy each new version separately.

Motoko Base is a standard Next.js (opens in a new tab) application, so you can deploy it on platforms that support Next.js.
